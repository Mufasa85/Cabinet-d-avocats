# 🔧 Guide de l'Administrateur - Cabinet ELMD

## Bienvenue sur le Guide d'Administration

Ce guide est destiné aux **Administrateurs du Cabinet ELMD**. Il vous explique comment gérer la plateforme sans avoir besoin de connaissances techniques.

---

## 🎯 Qu'est-ce que le Panneau d'Administration ?

Le panneau d'administration est un **espace sécurisé** qui vous permet de :

- 👥 **Gérer les utilisateurs** (avocats, stagiaires)
- 📝 **Modérer les articles** publiés
- 📁 **Gérer les documents** du cabinet
- ⚙️ **Configurer les paramètres** du système
- 🔔 **Envoyer des notifications** aux utilisateurs
- 📊 **Consulter les statistiques** d'utilisation

---

## 🚀 Comment Accéder à l'Administration ?

### 1. Se Connecter

1. **Ouvrez votre navigateur** (Chrome, Firefox, Edge)
2. **Accédez à la plateforme** du cabinet
3. **Cliquez sur "Connexion"**
4. **Entrez vos identifiants administrateur** :
   - Adresse email : celle que l'administrateur principal vous a fournie
   - Mot de passe : celui qui vous a été attribué
5. **Cliquez sur "Se connecter"**

### 2. Accéder au Tableau de Bord Admin

Une fois connecté avec un compte administrateur, vous verrez une option supplémentaire dans le menu :
- **"Tableau de bord Admin"** ou **"Administration"**

Cliquez dessus pour accéder au panneau de contrôle.

---

## 👥 Gestion des Utilisateurs

### Voir la Liste des Utilisateurs

Dans le menu Administration, cliquez sur **"Utilisateurs"** ou **"Membres"**.

Vous verrez un tableau avec :
- 📛 **Nom complet**
- 📧 **Email professionnel**
- 🎭 **Rôle** (Avocat, Stagiaire, Administrateur)
- 📅 **Date d'inscription**
- ✅ **Statut** (Actif, Inactif)

### Créer un Nouvel Utilisateur

1. Cliquez sur **"Ajouter un utilisateur"** ou **"Nouvel utilisateur"**
2. **Remplissez le formulaire** :
   - Nom complet
   - Adresse email professionnelle
   - Mot de passe temporaire
   - Rôle (Avocat ou Stagiaire)
   - Spécialités (optionnel)
3. Cliquez sur **"Créer"**

> 💡 **Conseil** : Envoyez les identifiants au nouvel utilisateur par email sécurisé.

### Modifier un Utilisateur

1. **Recherchez l'utilisateur** dans la liste
2. Cliquez sur **"Modifier"** ou **"Éditer"** (icône crayon)
3. **Modifiez les informations** souhaitées
4. Cliquez sur **"Enregistrer"**

### Désactiver/Supprimer un Utilisateur

Pour **désactiver** un compte (l'utilisateur ne pourra plus se connecter) :
1. Trouvez l'utilisateur
2. Cliquez sur **"Désactiver"** ou basculez le statut sur "Inactif"
3. Confirmez l'action

Pour **supprimer** définitivement un compte :
1. ⚠️ **Attention** : Cette action est irréversible
2. Cliquez sur **"Supprimer"**
3. **Confirmez la suppression**

---

## 📝 Modération des Articles

### Voir tous les Articles

Dans le menu, cliquez sur **"Articles"**.

Vous verrez la liste de tous les articles avec :
- 📌 **Titre** de l'article
- ✍️ **Auteur**
- 📂 **Catégorie** (Droit OHADA, Droit Minier, etc.)
- 📊 **Statut** (Brouillon, Publié, Archivé)
- 📅 **Date de publication**

### Approuver/Refuser un Article

Si vous avez activé la **modération** :

1. ** Consultez les articles en attente**
2. Cliquez sur **"Voir"** pour lire l'article
3. Vous avez le choix entre :
   - ✅ **"Approuver"** : L'article sera publié
   - ❌ **"Refuser"** : L'article reste en brouillon avec un message pour l'auteur

### Modifier ou Supprimer un Article

1. **Trouvez l'article** dans la liste
2. Cliquez sur **"Modifier"** pour éditer
3. Ou cliquez sur **"Supprimer"** pour retirer l'article

> 💡 **Conseil** : En cas de contenu inapproprié, supprimez d'abord l'article, puis contactez l'auteur.

## 📁 Gestion des Documents

### Types de Documents

Vous pouvez gérer tous les documents uploadés sur la plateforme :
- 📄 Contrats
- 📋 Mémoires et conclusions
- 📨 Correspondances
- 🏛️ Documents officiels

### Voir les Documents

1. Cliquez sur **"Documents"** ou **"Fichiers"** dans le menu
2. **Filtrez par type** si nécessaire
3. **Recherchez** par nom ou date

### Gérer les Documents

- **Télécharger** : Cliquez sur le nom du fichier
- **Supprimer** : Cliquez sur l'icône corbeille
- **Changer les permissions** : Public ou Privé

### Paramètres Généraux

Cliquez sur **"Paramètres"** ou **"Configuration"** dans le menu.

#### Informations du Cabinet
- 🏛️ **Nom du cabinet**
- 📍 **Adresse**
- 📞 **Téléphone**
- 📧 **Email de contact**

#### Paramètres du Site
- 🌐 **Langue par défaut**
- 📅 **Format de date**
- 🖼️ **Logo du cabinet**

### Notifications

Configurez les notifications automatiques :
- ✅ Envoyer un email quand un nouvel utilisateur s'inscrit
- ✅ Envoyer un email quand un article est publié

## 📊 Statistiques d'Utilisation

### Consulter les Stats

Cliquez sur **"Statistiques"** ou **"Tableau de bord"** pour voir :

| Statistique | Description |
|-------------|-------------|
| **Utilisateurs actifs** | Nombre de personnes connectées ce mois |
| **Articles publiés** | Total des articles en ligne |
| **Visites du site** | Nombre de visiteurs uniques |
| **Documents uploadés** | Espace de stockage utilisé |

### Exporter des Rapports

Pour obtenir un rapport détaillé :
1. Cliquez sur **"Exporter"** ou **"Générer un rapport"**
2. **Choisissez la période** (semaine, mois, année)
3. **Sélectionnez le format** (PDF ou Excel)
4. Cliquez sur **"Télécharger"**

---

## 🔔 Envoyer des Notifications

### Notifications aux Utilisateurs

1. Cliquez sur **"Notifications"** dans le menu
2. **Composez votre message** :
   - Destinataires (tous, avocat, stagiaire, ou individu)
   - Objet du message
   - Contenu du message
3. Cliquez sur **"Envoyer"**

### Notifications aux Visiteurs (Public)

Pour les messages visibles sur le site :
1. Cliquez sur **"Annonces"** ou **"Messages publics"**
2. **Créez une annonce**
3. Choisissez la **durée d'affichage**

---

## 🔒 Sécurité et Maintenance

### Changement de Mot de Passe

Pour changer **votre propre mot de passe** :
1. Allez dans **"Mon Profil"**
2. Cliquez sur **"Changer le mot de passe"**
3. Entrez l'ancien mot de passe
4. Entrez le nouveau mot de passe
5. **Confirmez le nouveau mot de passe**
6. Cliquez sur **"Enregistrer"**

### Réinitialiser le Mot de Passe d'un Utilisateur

1. Allez dans **"Utilisateurs"**
2. **Trouvez l'utilisateur** concerné
3. Cliquez sur **"Réinitialiser le mot de passe"**
4. Un **nouveau mot de passe temporaire** sera généré
5. **Envoyez-le à l'utilisateur** par email sécurisé

### Journal d'Activité (Logs)

Le système enregistre toutes les actions importantes :
- ✅ Connexions réussies et échouées
- ✅ Modifications de contenu
- ✅ Upload et suppression de fichiers
- ✅ Changements de permissions

Pour consulter les logs :
1. Cliquez sur **"Logs"** ou **"Historique"**
2. **Filtrez par date** ou par type d'action

## 🛠️ Dépannage

| Problème | Solution |
|----------|----------|
| **Un utilisateur ne peut pas se connecter** | Vérifiez que le compte est actif. Réinitialisez son mot de passe. |
| **Un article ne s'affiche pas** | Vérifiez le statut (brouillon ou publié). Effacez le cache. |
| **L'upload de fichier ne fonctionne pas** | Vérifiez que le format est PDF et que la taille est < 5 Mo. |
| **Le site est lent** | Vérifiez l'espace disque. Consultez les logs pour identifier le problème. |
| **Un message d'erreur apparaît** | Notez le message et contactez le support technique. |

---

## 📞 Signaler un Problème Technique

Si vous rencontrez un **problème technique non résu** :

1. **Documentez le problème** :
   - Ce qui s'est passé
   - Ce que vous essayiez de faire
   - Les messages d'erreur affichés
   - La date et l'heure

2. **Contactez le support technique** avec ces informations

3. **En cas d'urgence** (site indisponible), contactez immédiatement le développeur.
